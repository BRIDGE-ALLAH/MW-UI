**The Interface Language of a Living Knowledge Ecosystem.**

**Observe. Understand. Preserve.**

Moonwitness UI is an open-source interface foundation for building coherent, accessible, and evidence-conscious digital experiences across the MoonWitness ecosystem.

## What it provides

- Semantic design foundations for color, typography, spacing, surfaces, and motion.
- Composable interface primitives for forms, navigation, dialogs, feedback, and layout.
- Reusable interaction patterns for loading, errors, empty states, permissions, and confirmation.
- Evidence-aware presentation patterns for source identity, attribution, provenance, citations, and uncertainty.
- Documentation, examples, registry tooling, and integration guidance.

## Design philosophy: Evidence-First Moonpunk

The visual language brings together a celestial observatory, evidence-first editorial design, and instrumental operations. It should feel distinctive and precise without sacrificing readability.

Use expressive accents with restraint. Keep content legible. Make state explicit. Respect reduced motion. Never use color as the only carrier of meaning.

## Core principles

1. Clarity before spectacle.
2. Evidence before assertion.
3. Accessibility by default.
4. One foundation, many experiences.
5. Human responsibility.
6. Traceability by design.

## Relationship to MoonUI

Moonwitness UI is the product identity of this repository. The MoonWitness XV master design separately identifies **MoonUI / `@moonwitness/moonui`** as its certified shared design-system implementation.

These are related ecosystem efforts, not interchangeable package names. This repository currently retains its React, Next.js, Tailwind CSS, and shadcn-style registry foundation. Any migration to the certified MoonUI implementation must be agreed, tested, and documented by the relevant owners.

## Evidence and integrity

UI components render information supplied by their owning services. They must not fabricate source identities, citations, permissions, rights status, review approvals, confidence values, or operational metrics.

Show unknown, unavailable, simulated, and not-reviewed states honestly. Preserve source attribution and the context needed to inspect a claim.
